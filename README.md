# Environment Setup
To set up the environment, please ensure your Python version is `Python 3.8`.
Then, use the following command to install the required packages:

```shell
pip install -r requirements.txt
```

Please note that the specific PyTorch versions for this project are:
```
torch==1.12.1+cu113
torchvision==0.13.1+cu113
```

# Running the Project
Execute the following command to run the project:

```bash
bash run.sh
```
